Preparar galería de evento

Arrastra las fotos ya editadas. Aquí mismo se generan las versiones web, las miniaturas y el índice de rostros para la búsqueda por selfie. Nada se sube a internet desde esta página: todo se guarda en la carpeta del evento en tu computadora.

01 Carpeta del evento

Elige la carpeta del evento dentro de tu copia del repo galerias (por ejemplo galerias/casa1916-casino). Si ya tiene fotos indexadas, las nuevas se agregan sin duplicar.

Este navegador no permite escribir carpetas. Usa Chrome o Edge en computadora; si no, al final se descargará un .zip con todo para descomprimir dentro de la carpeta del evento.

02 Fotos

JPG exportados de Lightroom (lado largo de 2500 px o más está bien). Se ordenan por nombre de archivo.
